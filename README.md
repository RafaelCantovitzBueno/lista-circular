# Lista Circular em C 🔁

Este repositório contém um projeto desenvolvido em linguagem C como parte de atividades acadêmicas no **3º semestre** da faculdade de **Análise e Desenvolvimento de Sistemas** em **2023**.

> ⚠️ **Aviso:** Este projeto foi feito durante minha formação, e representa meu nível de conhecimento na época. Ele é mantido aqui como registro da minha evolução como desenvolvedor.

---

## 🛠️ Tecnologias Utilizadas
- Linguagem principal: C  
- IDE sugerida: Visual Studio Code / Code::Blocks / Dev-C++  
- Bibliotecas: `stdio.h`, `stdlib.h`  
- Plataforma: Console (Windows/Linux)

## 🚀 Instalação e Execução
### ✅ Pré-requisitos  
Certifique-se de ter instalado:
- GCC (compilador C)
- Ambiente de desenvolvimento (como VS Code, Dev-C++ ou Code::Blocks)

### 📌 Passos para instalação
Clone o repositório:
```bash
git clone https://github.com/RafaelCantovitzBueno/lista-circular.git
cd lista-circular
```
Compile o programa:
```bash
gcc Lista_Circular.c -o lista_circular
```
Execute o programa:
```bash
./lista_circular
```

## ✨ Funcionalidades
✔ Criação de uma lista circular encadeada  
✔ Inserção de nós no início  
✔ Inserção de nós no final  
✔ Inserção de nós em forma ordenada  
✔ Remoção de elementos por valor  
✔ Busca de elementos na lista  
✔ Listagem de todos os elementos com indicação de início  
✔ Validações de entrada e mensagens de erro adequadas
